Descriptions, not closuresgt-04-cl.tex def:samplerC4a TESTED

Compress consumes code. A Julia closure with a hidden environment is not code, and the type system says so out loud.

This is the requirement that shapes the whole prototype. Compress must measure a verifier's length, substitute static parameters into it, and emit new code — so a runtime function value will not do. Every sampler in the package is therefore asked four questions, and a sampler that cannot answer them from its own bytes is returned as NotDescribable rather than silently working.

Why the paper cares

The compression machine's output sampler must depend only on λ and universal constants — never on the input verifier's bytes — or the recursion does not close. That is a statement about code dependencies, and it can only be tested on objects that have code.

§5

Conditionally linear samplersgt-07-ldt.tex:203–237C4a TESTED

The question distribution is not arbitrary: a seed is read in stages, and each stage's linear map may depend only on what earlier stages produced.

This is the structural constraint the whole construction is organised around. A conditionally linear map of level ℓ splits the ambient space into ℓ factor registers; it reads the first, applies a linear map to it, and only then chooses the linear map for the second. For (q,m,d) = (8,2,1) the ambient space is Vpt ⊕ Vcoord ⊕ Vdir, of dimension 5, and the three maps of the low-degree test sit at levels 1, 2 and 3.

The classical low-degree testgt-07-ldt.tex fig:ld-deciderC4c HELD — no claim row

Ask for a point and a line through it. A cheating prover must either break the degree bound or contradict itself where they meet.

This chapter's evidence exists and is on disk, but there is no claim row for it. verdicts/tb1-r4.md holds the proposed row C4c at HOLD: the headline negative fact off_line_hits = 0 has no red witness — the counter can be replaced by a constant and the whole suite stays green. One assertion and one registered mutant would close it.

The decider Dld sees two typed questions and two answers. If the types are equal it demands equal answers. If one is a point and the other a line through that point, it demands that the line polynomial has degree at most d (axis) or md (diagonal) and that evaluating it at the point reproduces the point answer. If nothing applies, it accepts.

§7

Tseitin and arithmetizationgt-10-answer-reduction.tex prop:tseitin-arith-degreeC8 TESTED

Individual degree is fan-out. On the real six-gate circuit one variable reaches degree 6, not 2.

Tseitin turns a circuit into a formula by giving every gate a wire variable and asserting each gate's local relation; arithmetization turns that formula into a polynomial by sending ∧ to ×, ¬ to 1−·, and ∨ through De Morgan. The arithmetization of a formula tree is multilinear in its leaf occurrences, so a variable's individual degree is bounded by how many times it appears — which grows with the fan-out of the gate that produced it.

Finding F1 — stated softly, on purposedocs/findings.md · C8 TESTED (scoped)

Our reading of the NW19 Tseitin gadget may be wrong. With that caveat first: reading z_i := (g_i ∧ w_i) ∨ (¬g_i ∧ ¬w_i) and arithmetizing along the formula tree gives occ(w_i) = 2 + 2·fanout(gate i) and occ(x_j) = 2·fanout(input j), so a fan-out-2 gate already reaches individual degree 6. The proposition in gt-10 states 2.

The theorem survives. The surviving weaker statement is deg_v(F_arith) ≤ 2(1 + fanout_max); with copy gates enforcing fan-out ≤ 2 that is ≤ 6, so c₀ has individual degree ≤ 7 and the Schwartz–Zippel bounds become (6+5d)m′/q and (2+d)m′/q — fine as long as d ≥ 7, and the paper's d = k ≥ 11. The individual-degree-3 statement for c₀ in the completeness proof inherits the same correction.

A second note, F2: NW19's F := z₁ ∧ … ∧ z_s constrains w to be the wire values but never asserts the output wire is 1, so it is satisfiable for every x. The MIP*=RE definition states the contract rather than the construction, so the implementation adds the conjunct w_out — one more occurrence, giving 3 + 2·fanout.

Exactly what C8 is allowed to say

TESTED, and scoped: the individual degrees of a real Tseitin arithmetization were computed, they equal the occurrence counts, and the mutants that would hide the discrepancy are killed. It is not a claim that the paper is wrong — it is a claim about what this arithmetization does on these circuits.

§8

The zero basisgt-10-answer-reduction.tex prop:zero-basisC2 TESTED

"Vanishes on the Boolean cube" becomes a coefficient identity — an object the verifier can check with a handful of point queries.

The PCP's central object is a polynomial c₀ built so that it vanishes on {0,1}n exactly when the underlying circuit is satisfied. Vanishing on the cube is equivalent to lying in the ideal generated by z_i(1 − z_i), so the prototype divides c₀ by that ideal and keeps the quotients as part of the proof. If the division leaves a remainder, no certificate is issued.
